# 简简单单的新闻

多源新闻聚合桌面工具，自动采集国内主流媒体新闻，支持 AI 要点总结和全文爬取。

## 下载

[⬇️ 下载最新版](https://github.com/Rainier-Z/very-simple-news/releases/latest)

下载 `news-collector-win.exe`，双击运行即可。

## 功能

- **自动采集** — 每日 7 家国内主流媒体新闻（新华社、人民日报、央视、澎湃、财新、36氪、新浪）
- **要点总结** — 选中感兴趣的文章，AI 自动生成摘要、关键要点和背景信息
- **爬取全文** — 一键保存文章全文为本地 txt 文件
- **收藏与标记** — 收藏感兴趣的文章，标记已读状态
- **搜索与筛选** — 按来源、分类、日期、关键词快速筛选
- **明暗主题** — 支持亮色/深色模式切换

## 使用

下载 exe 后直接双击运行，浏览器自动打开新闻页面。无需安装，无需配置。

> 首次启动会自动采集当日新闻，请保持网络通畅。

## 技术栈

Python + Flask + SQLite + PyInstaller
